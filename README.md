# PySpark Assignment – 


This project implements a PySpark data pipeline that:
1. Reads raw customer, product, and order data from Excel, CSV, and JSON files.
2. Cleans and enriches the data.
3. Joins orders with customer and product details.
4. Aggregates profit by year, category, sub-category, and customer.

The pipeline is tested end-to-end using `pytest`.
